# 全站 UI 统一检查

日期：2026-10-09。对应客户要求：统一 Tab 样式，检查整个 UI，左侧常用与不常用菜单分区。

## 修改结果

- 记录、销售以及销售配置二级栏目统一使用 Radix Tabs 和共享样式：墨绿色选中文字、下划线、统一高度与键盘焦点，支持方向键和 Home / End。删除页面原有按钮切换及旧 Tab 样式。
- 桌面侧栏分为「常用功能」和「管理与设置」。常用区依次为工作台、库存、开单与收款、记录、清点库存；管理区为人员与权限、数据与备份、版本更新。保留账号权限过滤。
- 全站输入框、下拉框、按钮、复选框、弹窗沿用共享控件。必填下拉框接入中文行内错误、错误边框、首个错误焦点定位，并在选择后清除错误。
- 修复普通开单账号进入配置时默认停在不可访问的类型配置，改为客户栏目，支持快速建档。
- 销售页面复选框、金额面板、边框与文字颜色使用共同主题；表格焦点和更新进度采用同一墨绿色。手机销售金额单独成行，避免货币金额折断。
- 销售打印样式仅在打印预览存在时隐藏其他内容，修复进入销售后普通页面打印空白的问题。单据纸张继续使用黑白 A4 样式。

## 验证范围

检查工作台、库存、销售、记录、清点、人员权限、数据备份、版本更新及相关弹窗。浏览器回归覆盖 1280×800、1024×600、800×480、375×667、320×568、667×375 六种尺寸。

自动化验证包含 Tab 样式跨页面一致性、键盘切换、侧栏分区、必填下拉反馈、普通账号客户建档、普通页面打印可见性，以及原有销售、库存、备份、权限、会话和更新流程。完整测试和各平台 GitHub Actions 结果以 [PR #1](https://github.com/7link-team/easy-erp/pull/1) 的最新检查为准。

手机保留现有底部导航和「更多」入口，分区标题在桌面侧栏显示。实体打印机、原生手机真机打印以及本机系统对局域网连接的限制仍需在实际部署环境验证。
