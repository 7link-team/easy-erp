# 全站 UI 统一检查

> 本文记录 2026-10-09 当时的实现。当前导航为 14 个业务菜单，退货并入单据筛选；收款、账户、业绩三个菜单定位同页分区，版本移至关于。后续界面、权限及验证结果以 [需求复核](./20261009-需求复核.md) 为准，以下历史菜单和测试数量不代表当前版本。

日期：2026-10-09。对应客户要求：统一 Tab 样式，检查整个 UI，左侧常用与不常用菜单分区。

## 修改结果

- 记录、销售以及销售配置二级栏目统一使用 Radix Tabs 和共享样式：墨绿色选中文字、下划线、统一高度与键盘焦点，支持方向键和 Home / End。删除页面原有按钮切换及旧 Tab 样式。
- 桌面侧栏分为「常用功能」和「管理与设置」。常用区依次为工作台、库存、开单与收款、财务、记录、清点库存；管理区为人员与权限、数据与备份、版本更新。保留账号权限过滤。
- 表单网格统一按网格间距排列，移除字段底部间距叠加；财务标题、表格、筛选区保持 16px 间隔，桌面三项筛选同行，窄屏单列。
- 全站输入框、下拉框、按钮、复选框、弹窗沿用共享控件。必填下拉框接入中文行内错误、错误边框、首个错误焦点定位，并在选择后清除错误。
- 修复普通开单账号进入配置时默认停在不可访问的类型配置，改为客户栏目，支持快速建档。
- 销售页面复选框、金额面板、边框与文字颜色使用共同主题；表格焦点和更新进度采用同一墨绿色。手机销售金额单独成行，避免货币金额折断。
- 销售打印样式仅在打印预览存在时隐藏其他内容，修复进入销售后普通页面打印空白的问题。单据纸张继续使用黑白 A4 样式。

## 验证范围

检查工作台、库存、销售、财务、记录、清点、人员权限、数据备份、版本更新及相关弹窗。浏览器回归覆盖 1280×800、1024×600、800×480、375×667、320×568、667×375 六种尺寸。

自动化验证包含 Tab 样式跨页面一致性、键盘切换、侧栏分区、必填下拉反馈、普通账号客户建档、普通页面打印可见性，以及原有销售、库存、备份、权限、会话和更新流程。完整测试和各平台 GitHub Actions 结果以 [PR #1](https://github.com/7link-team/easy-erp/pull/1) 的最新检查为准。

手机保留现有底部导航和「更多」入口，分区标题在桌面侧栏显示。实体打印机、原生手机真机打印仍需在实际部署环境验证。

## 财务入口与对账补充

财务作为桌面常用区独立入口，手机从「更多 → 财务」进入；管理员可访问 `#/finance`，刷新仍停留该页面。顶部汇总销售应收、净实收、客户欠款，下方共享 Tab 分为客户欠款、账户流水、部门业绩。

客户名称可打开客户单据对账，点击单号直接查看明细并登记收款、退款或更正，完成后返回财务。账户栏目列出累计收款、累计退款、净收款，并保留日期 / 账户筛选和 CSV 导出。销售应收不会直接算作现金，实际登记收款才增加相应账户净收款。

本机局域网空响应定位为 macOS 防火墙拒绝未签名调试服务，日志显示 `Designated requirement not obtained for flow, dropping flow`。预览改用单独复制并本地签名的服务文件，原演示数据库保留；局域网页面、状态接口均已验证 HTTP 200，未关闭防火墙。开发环境处理方式见《构建环境与平台边界》。

### 可输入下拉与直接配置入口

新增共享 `ComboBox`，规格、物料类型、单位、单据类型统一使用。输入框保持统一 44px / 手机 48px，支持输入过滤、鼠标/触控选择、方向键、Enter 和 Escape；弹窗内 Escape 优先收起候选，保留字段焦点，不丢表单。输入产生的候选只在业务提交成功后保存。

客户和基础资料已移到独立侧栏入口，配置只保留一层共享 Tab。手机从「更多」直接进入对应页面，不经开单页面。桌面导航可滚动以适配较矮屏幕。库存行新增「开单出库」，手机操作继续换行且不横滑。
