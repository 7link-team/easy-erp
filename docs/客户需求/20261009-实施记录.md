# 客户需求实施记录

日期：2026-10-09。对应方案：`20261009-实施方案.md`。

## 已实现

- 多物料销售草稿、确认与精确金额计算；确认整单事务扣库存，打印与草稿不扣。
- 自定义计款 / 不计款类型、客户、公司信息、收款账户、部门和部门业务员。
- 折扣与抹零、分次收款 / 补收、退款、资金冲销更正、欠款对账与 CSV 导出。
- 独立财务入口，客户单据对账可直接补收，账户累计收款 / 退款 / 净收款及部门业绩栏目。
- 最高权限修订、净库存差额调整、版本冲突检查、部分退货、作废及审计。
- 部门 → 业务员两级业绩归属，独立于开单人，保存历史快照；按有效计款单的退货后应收汇总业绩、净实收和欠款。
- 最多两张活动签字凭证，真实图片校验，数据库 BLOB 随备份一并恢复。
- A4 系统打印，长名称、多页分页；原生端通过受控单次登录链接打开系统浏览器打印。
- 数量默认最多三位小数，展示去末尾零；旧余额与历史单据不重算。
- 升级销售表结构前自动备份；旧备份经临时副本迁移后恢复；拒绝财务关系不一致的备份。

## 技术及实际边界

数据访问沿用 SeaORM 的连接、参数化 SQL 和事务。SeaORM SQLite 驱动基于 SQLx；原有备份恢复需要固定连接执行 ATTACH 和事务，因此通过 SeaORM 暴露的 SQLx 接口处理，不是引入第二套业务 ORM。

数量最多三位、单价最多四位、结算金额按分精确计算。不支持无限小数。调货只是自定义出库类型，不包含多仓调拨。轻量财务记录应收与资金流水，不包含成本利润、采购、税务或总账。

业绩汇总当前按全部有效计款单、部门和业务员分组，不计草稿、作废或不计款单；未分配归属显示「未指定」，管理员可修订补录。业务员配置不自动建立登录账号或放宽单据查看权限。

当前备份数据库上限为 512 MB，包含凭证图片；超出会明确拒绝生成备份。历史移除凭证保留以供审计。

系统浏览器打印跳转、独立登录、同一单据预览及 PDF 已纳入 E2E。尚未连接客户实体打印机验证纸张、驱动或原生 Android / iOS 真机打印。
