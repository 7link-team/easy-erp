# 桌面与移动界面设计

## 桌面启动

首次选择「保存在这台电脑」或「连接已有库存主机」，验证成功后保存选择并直接打开内嵌库存页面。再次启动自动恢复选择；本机模式自动准备后台服务。已有本机连接配置兼容读取，不要求重复配置。

业务窗口承载完整工作台、库存、收发、记录、盘点与管理功能。连接页仅用于首次配置、连接失败或主动更换主机。未登录时显示登录页面；记住登录有效时直接显示业务页面。

原生应用菜单及托盘提供「打开库存管理」「在浏览器中打开」「连接与启动设置」。关闭窗口收起到托盘，退出桌面不停止独立后台服务。可选登录电脑后自动显示托盘。随包服务不等同于已安装操作系统守护服务，当前不承诺注销电脑后继续运行。

移除主机设置码。首次在本机创建管理员仍保留；不取消账号、密码、权限及审计。首次初始化仅接受回环地址，继续保留来源与请求头检查和一次性初始化保护。

## 登录续期

采用可撤销的服务端随机会话和 HttpOnly Cookie，不引入 JWT。普通登录使用 8 小时滑动窗口，记住登录使用 30 天滑动窗口；成功的业务请求自动续期，最多每 5 分钟续写一次。页面键盘和点击交互也会限频检查登录，避免一直填写表单时缺少请求；闲置页面不通过定时心跳永久保活。

过期、退出、停用账号、重置密码、权限更改及恢复备份后，被撤销的会话不能续期复活。旧的有效会话保留，原记住登录会话在下一次续期时使用 30 天窗口。登录策略迁移不改变业务备份格式，恢复时仍清除全部会话。

## 视觉规范

最新主题规范以 `../design-system/inventory/MASTER.md` 为准：墨绿—青碧渐变导航与库存概况、暖灰工作区、实体白色列表；保留紧凑应用结构。新备份统一使用 ZIP 后缀，旧后缀仍可恢复。用户可见术语统一为清点、备份份数、系统记录数量等日常说法。

依据 ui-ux-pro-max 的对比度、触控、响应式与性能规则，采用深墨绿渐变侧栏、青碧渐变库存概况和暖灰工作区。表单和列表使用实体白色背景。工作台以库存概况、紧凑操作入口和近期记录为核心，保留小尺寸操作入口。

使用系统中文字体与统一 Lucide 图标，无外部字体请求。静态渐变、轻阴影和短状态过渡，不使用大面积背景模糊、循环装饰动画；尊重减少动态效果设置。本轮为浅色主题。

## 手机交互

760px 以下显示底部导航：工作台、库存、记录、清点库存、更多；按权限隐藏盘点入口。人员、数据备份与退出登录收进「更多」。底栏适配底部安全区域，内容预留底栏空间。

表单弹窗改为底部面板，标题和关闭按钮保留，内容独立滚动。输入框有明确标签、限制、示例与展开说明。手机库存表格转换为物料列表，名称、数量、状态和收发按钮在一屏宽度内显示，不复制业务 DOM。其他宽表格保留完整列和滚动提示，支持触摸横滑及键盘方向键。

页面用 hash 保存位置，刷新保留所在页面；浏览器返回与页面返回共享历史，未提交收发草稿离开前确认。提交成功后的「返回工作台」明确进入工作台，与「返回」区分。

## 当前验证边界

本轮只交付本机 Web 和 macOS 桌面。浏览器验收包含 320px、375px 手机、667px 横屏和三种桌面尺寸；桌面内嵌业务窗口通过实际进程启动检查。原生托盘点击、系统自启、真实手机软键盘仍需设备验收；浏览器模拟不替代这些检查。
