库存管理 v0.2.1 正式版。

### 关于页面

- 增加源码仓库与版本发布（Release）入口，显示完整地址，方便查看源码、更新说明和下载各平台安装包。
- Web 端在新标签页打开；桌面与移动应用通过系统浏览器打开配置的项目地址。打开失败时提示复制地址访问。
- 统一链接图标、对齐、键盘焦点及手机窄屏换行。

### 开发与测试目录

- 报告、截图、临时资料和检查缓存统一写入 `build-artifacts/`，避免在项目根目录散落生成文件。
- Chromium 与 WebKit 分别保存报告和测试附件；同步调整性能脚本、模拟器检查及 GitHub Actions 附件路径。`dist`、`target` 等工具标准构建目录保留原位。

### 下载与升级

- 桌面端可检查更新，或在本页下载对应平台安装包；Web 与移动端需连接库存服务。
- iOS 仅提供模拟器包，不是真机 IPA。macOS 尚未配置 Apple 开发者公证，Windows 安装包尚未配置发行者代码签名；桌面自动更新包使用独立更新签名验证。
- 升级前保存当前操作并另存一份备份。大库升级、备份空间及旧版恢复兼容性的说明继续适用，详见 [v0.2.0 发布说明](https://github.com/7link-team/easy-erp/releases/tag/v0.2.0)。
