库存管理 v0.1.4 正式版，默认稳定版渠道可检查并安装本次更新。

### Windows 安装与升级

- 新安装默认供所有用户使用，程序路径为 `C:\Program Files\EasyERP`；也可选择仅当前用户安装。
- 程序安装路径使用英文，支持自选路径并在升级时保留。修复切换安装范围后的快捷方式、启动项和旧程序残留问题。
- 库存数据统一放在当前用户的 `C:\Users\<用户名>\EasyErp`，备份放在其中的 `backups` 文件夹。旧版本数据升级时自动备份并迁移；目标目录冲突时停止迁移，避免覆盖。
- 手动安装与应用内更新均会协调关闭旧程序和服务；卸载程序保留库存、账号和备份。不同 Windows 用户的数据相互独立，共用库存请连接同一库存服务。

### 自动备份

- 固定每小时自动备份一次，只需设置保留天数，默认 7 天，可选 1–365 天。
- 保留期限内的全部备份；新备份成功且验证通过后才清理过期文件，始终保留最新备份。
- 简化备份设置和说明，移除开关、频率、每日时间和每周保留数量等选项。

### 下载说明

- 提供 Windows 安装程序、macOS Intel / Apple Silicon、Linux AppImage / deb、Web、Android APK / AAB，以及独立库存服务。
- iOS 仅提供模拟器包，不是真机 IPA。macOS 尚未配置 Apple 开发者公证；Windows 安装包尚未配置发行者代码签名。桌面自动更新包使用独立更新签名验证。
- Web 和移动端需连接库存服务；升级前建议另存一份备份。
