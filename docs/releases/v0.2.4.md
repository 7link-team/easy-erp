## 文件存储与完整备份

- 附件、签字凭证图片及完整备份支持本地目录或 S3 兼容存储，通过 Compose / 环境变量配置；SQLite、MySQL 均可使用。
- 图片与备份分目录保存，备份按 UTC 年/月/日归档。备份清单直接从存储发现，每份备份配套元数据；元数据丢失时仍可读取备份。
- 保留天数独立保存在 `backups/policy.json`，清空业务数据不会删除备份及保留策略。成功生成完整备份后清理过期归档和元数据，始终保留最新一份。
- 完整备份包含历史凭证图片，恢复不依赖原 S3。兼容旧版数据库内图片和原平铺备份，支持在线及桌面本机维护恢复。
- Compose 支持直接提供 MySQL 连接及初始化口令，并提供 S3 配置示例。

## 服务器镜像

```sh
docker pull ghcr.io/7link-team/easy-erp-server:v0.2.4
```

支持 Linux amd64 / arm64。镜像地址：[GHCR](https://github.com/orgs/7link-team/packages/container/package/easy-erp-server)。私有镜像需先登录有权限的 GHCR 账号；Release 不附带镜像归档。

部署文件：[compose.yaml](https://github.com/7link-team/easy-erp/blob/v0.2.4/compose.yaml) · [MySQL 示例](https://github.com/7link-team/easy-erp/blob/v0.2.4/compose.mysql.yaml) · [S3 示例](https://github.com/7link-team/easy-erp/blob/v0.2.4/compose.s3.yaml) · [配置说明](https://github.com/7link-team/easy-erp/blob/v0.2.4/README.md#文件存储本地目录--s3)

## 升级说明

- 升级前保存操作并另存完整备份，保留原持久卷。新上传图片使用配置的文件存储；旧数据库内图片无需搬迁。
- 切换存储只影响新文件，不自动迁移历史文件；切回本地时保留原 S3 连接配置。变更本地目录、Bucket 或 prefix 前先迁移文件，每套系统使用独立 prefix。
- S3 模式仍需要本地配置及备份临时空间。启用 S3 版本控制时，历史版本空间回收需要配置 Bucket 生命周期。
- 本版不包含“锁定备份”或“备份失败主动提醒”。iOS 模拟器包不是真机安装包。
