## 安装包说明

- macOS：Intel、Apple Silicon 安装包；Windows：安装程序；Linux：AppImage、Deb。
- Android：APK/AAB；iOS：仅模拟器包，无 Apple 开发者签名，暂不提供真机 IPA。
- Web 包需配合库存服务运行。
- macOS 尚无 Apple 公证；首次安装可能需要在系统“隐私与安全性”中允许打开。

正式版渠道只接收已公开的正式版本；预览渠道可接收已公开的测试版本及正式版本。
