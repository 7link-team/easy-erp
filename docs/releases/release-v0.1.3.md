## Windows 启动修复

- 修复未安装 Visual C++ 运行库的新电脑启动时提示“找不到 VCRUNTIME140.dll”的问题。
- 桌面程序和内置库存服务统一静态链接 Visual C++ 运行库。
- 发布前检查桌面程序、内置服务和独立服务的 DLL 依赖，阻止再次发布依赖外部 VC 运行库的包。
- 托盘提供“仅退出界面（共享继续）”与“全部退出（停止本机共享）”两个选项。
- 手动安装及应用内更新会备份库存、停止旧服务和关闭旧界面，安装完成后可启动新版。
- 升级直接覆盖安装，不再要求先卸载；卸载程序始终保留库存、账号、记录和备份。

已安装 0.1.2 且无法启动的 Windows 用户，请下载本页 Windows 安装程序覆盖安装；无需卸载或删除库存数据。可正常启动的客户端可在“版本更新”页面升级。

本版本不修改库存数据结构。仍默认使用稳定更新渠道。

iOS 文件仅供模拟器使用，不是真机 IPA。macOS 安装包尚无 Apple 公证。
