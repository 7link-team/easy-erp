库存管理 v0.2.2 正式版。

### 备份与本机数据维护

- 完整备份列表增加分页，每页 10 条，显示总数与页码；生成备份后返回首页，备份过期清理后自动调整页码。
- 备份页面新增“本机数据维护”入口，也可从桌面顶部菜单、托盘菜单或启动页进入。
- 支持清空数据（不含备份数据）、从本机或外部 ZIP / 旧版备份恢复、单独清空备份。维护窗口显示本机目录，连接远程库存时也只维护本机，不会清空远程主机。
- 清空与恢复必须输入对应确认文字；操作期间禁止关闭，完成后可继续维护或返回启动页。清空业务数据保留已有备份；恢复包含历史凭证图片。
- 库存服务无法启动时仍可进入维护。修复开发模式启动页被误判为无本机管理权限的问题。

### 桌面操作

- 自动更新提示等待窗口可见、无未保存内容或其他弹窗，并连续约 30 秒无操作后出现；选择“稍后”后本次运行不反复提醒同版本。
- 改进导航返回、单据列表与打印流程，保留未保存内容确认和已有权限限制。

### 下载与升级

- 桌面端可检查更新，或下载对应平台安装包。升级前保存正在编辑的内容，并另存一份完整备份。
- 本机数据维护中的清空不可撤销；需要保留当前库存时，请先自行备份。确认前务必核对窗口显示的数据目录。
- Web 与移动端连接库存服务使用；本机离线维护需要桌面版。开发可执行文件与安装包可能使用不同的登录存储，首次切换需重新登录；本版不改变登录有效期。
- iOS 仅提供模拟器包，不是真机 IPA。macOS 尚未配置 Apple 开发者公证，Windows 安装包尚未配置发行者代码签名；桌面更新包沿用既有更新签名。
- 大库升级、备份空间及旧版恢复兼容性限制继续适用，见 [v0.2.0 发布说明](https://github.com/7link-team/easy-erp/releases/tag/v0.2.0)。自动化测试不代替所有系统的实机验收，真实断电、磁盘写满和 Windows 实机维护尚未验证。
