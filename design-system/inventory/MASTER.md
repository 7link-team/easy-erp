# 库存管理 · 墨绿青碧主题

## 使用场景

桌面与手机的库存操作应用。保留紧凑导航、数量优先、直接收发的结构。ui-ux-pro-max 用于触控、对比度、响应式和性能规则；其通用展示页建议不适用本项目。用户明确要求可见渐变，因此采用静态品牌渐变，而非搜索结果中的无渐变默认方案。

## 色彩与分工

| 用途 | 颜色 / 渐变 | 位置 |
| --- | --- | --- |
| 品牌渐变 | `#133f3c → #17665c → #1e7768` | 库存概况、连接页标题区 |
| 导航渐变 | `#133330 → #17443e → #21685a` | 桌面侧栏、登录左侧 |
| 主按钮渐变 | `#17554a → #227e68` | 确认、新增、保存 |
| 暖灰底色 | `#f4f5f1` | 工作区 |
| 内容底色 | `#ffffff` | 表单、记录、物料列表 |
| 深色背景文字 | `#ffffff` / `#e1f1e8` | 标题、数字 / 说明 |
| 暖金点缀 | `#d5b881` | 导航选中标记 |

统一 CSS 变量位于 `src/theme.css`。渐变固定，不动画、不大面积模糊。出库图标用土金色，查询图标用灰绿色；数量文字不使用渐变填充。

## 组件

基础交互采用 Radix UI（Select、Checkbox、Dialog、Popover），统一封装于 `src/ui.tsx`。所有业务页面通过这层使用 Button、Input、Textarea、Select、Checkbox、Form、Disclosure、Modal；禁止在页面中自行绘制另一套通用控件。通用尺寸和状态只在 `src/controls.css` 定义：桌面控件高 44px，手机高 48px，圆角 8px；图标按钮与同行输入框等高。文本域为多行高度，不强行与单行控件等高。

输入错误显示中文行内提示，应用内离开确认使用统一弹窗；浏览器关闭标签页的防丢失提示以及操作系统文件选择窗口仍由系统控制。下拉列表和帮助浮层适配屏幕边界，支持键盘和触屏，关闭弹窗后恢复触发位置的焦点。字体、尺寸和禁用状态通过同一组变量控制，保留现有墨绿渐变。

删除只对管理员开放：零库存且无收发、清点记录的物料显示「删除」，弹窗显示名称、规格、编码，默认焦点在取消。提交时后台在写锁和事务内重新验证；有记录的零库存物料只显示「停用」。操作审计保留删除前的物料资料，不自动处理真实用户数据。

细节：顶部工具栏显示当前页面名称；导航用细暖金标记和内描边；表单标签与说明区分字号和字重；记录页使用浅底分段切换；数字保持等宽排列。面板使用轻阴影，弹窗使用独立阴影与遮罩，控制背景层次。

托盘：使用 Lucide Package 衍生的圆角单色箱体，与页面图标同一风格。源文件 `desktop/icons/tray.svg`；`node scripts/render-tray.mjs` 生成 36px RGBA，macOS 显示为 18pt 并使用原生模板着色。图标在构建前生成，运行时不依赖浏览器或图像解析库。许可见 `desktop/icons/LUCIDE-LICENSE`。

桌面：深色侧栏、浅色顶部工具栏、实体内容面板。手机：固定底栏、浅绿选中状态、顶部应用名称、横排操作入口、物料列表。

圆角以 7/10/12px 为主，弹窗手机顶部 16px。保留 44px 触控区域、键盘焦点和减少动态效果选项。表格与说明文字使用实体背景，避免渐变干扰阅读。本轮为单一浅色工作区主题，不提供多主题切换。

## 用户用语

| 原说法 | 显示用语 |
| --- | --- |
| 日／周恢复点 | 每日／每周备份保留份数 |
| 盘点 | 清点 |
| 账面数量 | 系统记录数量 |
| 作废冲回 | 作废调整；说明减去入库数量或加回出库数量 |
| 入账后库存 | 本次操作完成后的库存 |
| 期初入库 | 首次登记库存 |
| 台账 | 库存表格 |
| 主机 | 保存库存的电脑 / 库存电脑 |
| 撤销会话 | 所有人需要重新登录 |
| 数量精度 | 小数位数 |

技术细节放在展开说明中。备份直接使用 `.zip`；旧 `.erpbackup` 可继续恢复，不强制改名。新库存导入模板用日常用语，兼容旧模板的「期初数量」列。

工作台提供「在 Web 中打开」地址选择弹窗：保留当前连接地址，列出服务实际监听覆盖的 IPv4 地址，区分仅本机与其他设备访问。提供打开、复制和刷新；复制权限不可用时提示手动复制。手机以单列地址卡片展示。文件选择框统一显示「选择文件」「未选择文件」和已选文件名，保留原生文件输入的键盘、读屏和文件类型限制。
